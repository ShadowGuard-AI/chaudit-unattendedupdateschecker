Two Apt Files and One Package

chaudit-unattendedupdateschecker is a simple script to check if unattended upgrades are enabled and configured correctly on Debian and Ubuntu systems, reporting on the status and any misconfigurations.

It runs one dpkg -s check for the unattended-upgrades package and reads the two apt configuration files /etc/apt/apt.conf.d/50unattended-upgrades and /etc/apt/apt.conf.d/20auto-upgrades.

It can also validate a YAML or JSON configuration file against a JSON schema supplied by the user. No predefined schema or rule set ships with this tool.

Both Files or Neither

Code note: the two file arguments must be given together. Giving neither or only one is an error. The two modes, the upgrades check and the file audit, are independent and may run in the same invocation.

How the Check Truly Reads

Taken from main.py and labelled as code truth. There is no verified behaviour section in the source, and that absence is stated plainly here instead of borrowing confidence from elsewhere.

The package test trusts the return code of dpkg -s and never reads the status text it prints.

The 50unattended-upgrades test asks only whether the string for Allowed-Origins is present in the file.

The 20auto-upgrades test asks for two exact lines, character for character, APT::Periodic::Update-Package-Lists "1"; and APT::Periodic::Unattended-Upgrade "1";, in that one file.
